 Simple Calculator (CLI)

This project is a simple command-line calculator developed using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division. The calculator takes input from the user and displays the result in the terminal.

The project also includes error handling to manage invalid inputs and division by zero. It helped me understand Python basics such as user input, conditional statements, loops, and exception handling.
  
   Features
- Addition
- Subtraction
- Multiplication
- Division
- User input handling
- Invalid input handling

 Technologies Used
- Python
- VS Code

 Run Command

python calculator.py


Learning Outcome

Through this project, I improved my understanding of Python programming, user input handling, and arithmetic operations.
